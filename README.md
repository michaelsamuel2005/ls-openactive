University of Bristol · SEMTM0044 · 2025/26
Team: Michael, Clarence, Wesley, Fahmi
Project partner: London Sport

> Working repository. The project direction is being finalised with our supervisor, so this structure may still change.

## Setup
1. Clone the repo and cd into it.
2. Create and activate a virtual environment:
   python3 -m venv .venv && source .venv/bin/activate
3. Install dependencies:
   pip install -r requirements.txt

## Structure
- data/        raw and processed data (git-ignored — never commit datasets)
- notebooks/   exploratory analysis
- src/         reusable code / pipeline
- tests/       tests
- docs/        notes, methodology, data dictionary
- reports/     outputs and figures
